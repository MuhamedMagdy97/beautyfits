# BeautyFits Design References

This directory contains design references used during BeautyFits frontend implementation.

## Google Stitch

The original Google Stitch design export is located at:

`./google-stitch/`

Each subdirectory represents a specific BeautyFits screen or design concept.

These files are design references only and are not production frontend code.

When implementing the frontend, Claude Code should inspect the relevant Stitch reference before implementing the corresponding screen.

The production UI must be rebuilt using the actual BeautyFits Next.js/React architecture and project rules.
